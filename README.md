# NumPy Student Marks Analyzer 🎓

A beginner-friendly Python project built with **NumPy** to analyze student marks and calculate basic academic statistics. This project helped me practice NumPy arrays, numerical operations, conditional statements, and user input.

## 🚀 Features

- Display student marks
- Calculate total marks and average
- Find the highest and lowest marks
- Count passed and failed subjects
- Calculate a grade based on average marks
- Interactive menu using user input
- Handle invalid menu choices

## 🛠️ Technologies Used

- Python
- NumPy
- VS Code
- Git and GitHub

## 📦 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/numpy-student-marks-analyzer.git
   ```

2. Open the project folder:

   ```bash
   cd numpy-student-marks-analyzer
   ```

3. Install NumPy:

   ```bash
   pip install numpy
   ```

## ▶️ Run the Project

```bash
python marks_project.py
```

Follow the menu and enter your choice to perform different calculations.
